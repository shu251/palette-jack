Oceanography

Research vessel and oceanographic survey palettes

Palettes inspired by research vessels and oceanographic expeditions. The ROV Jason, R/V Atlantis, and HOV Alvin are workhorses of deep-sea science; their color schemes evoke their operational identity. This mode lets you pick one and get a copy-ready hex list for your figures.

library(tidyverse)
library(glue)

ocean <- read_csv("../data/oceanography-colors.csv")

swatch_html <- function(hex, cap = 8) {
  n <- length(hex)
  shown <- head(hex, cap)
  spans <- glue('<span class="mini-swatch" style="background:{shown}"></span>')
  out <- paste(spans, collapse = "")
  if (n > cap) out <- paste0(out, glue('<span class="palette-module-more">+{n - cap} more</span>'))
  out
}

gallery <- ocean |>
  arrange(palette, position) |>
  group_by(palette, display_name, description) |>
  summarise(
    n_colors = n(),
    swatches = swatch_html(hex),
    .groups = "drop"
  ) |>
  arrange(display_name)

cat(
  '<div class="palette-gallery">',
  glue_data(
    gallery,
    '<div class="palette-module">
  <h4>{display_name} <span class="palette-module-count">{n_colors} colors</span></h4>
  <p class="palette-module-desc">{description}</p>
  <div class="palette-module-swatches">{swatches}</div>
</div>'
  ),
  '</div>',
  sep = "\n"
)

How to use it

  1. Pick a palette from the dropdown below.
  2. Copy your choice — R vector (ready for scale_fill_manual()) or plain hex list.
  3. Paste into your code and scale your figures.

function oceanTextColor(hex) {
  const c = hex.replace("#", "");
  const r = parseInt(c.substring(0, 2), 16);
  const g = parseInt(c.substring(2, 4), 16);
  const b = parseInt(c.substring(4, 6), 16);
  const lum = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
  return lum > 0.6 ? "#241C1C" : "#FFFFFF";
}

oceanVectorCopyBtn = {
  const label = () => `Copy R vector (${oceanFiltered.length})`;
  const btn = html`<button class="swatch-copy-btn">${label()}</button>`;
  btn.onclick = () => {
    navigator.clipboard.writeText(oceanHexVector).then(() => {
      btn.textContent = "Copied!";
      setTimeout(() => { btn.textContent = label(); }, 1200);

}
