Werner

Randomized palettes from a 1814 color classification system

Abraham Gottlob Werner was a German geologist who, in the late 1700s, developed a standardized color-naming system so mineralogists could describe rock and mineral color consistently. In 1814 (2nd ed. 1821), Scottish flower painter Patrick Syme illustrated and expanded Werner’s system into 110 named colors, organized into 10 classifications (White, Grey, Black, Blue, Purple, Green, Yellow, Orange, Red, Brown) – each cross-referenced against an animal, a plant, and a mineral where that color occurs in nature. Charles Darwin carried a copy on the Beagle to describe organisms and landscapes with a shared, precise color vocabulary.

Palette Jack’s Werner mode lets you filter by classification and pull a randomized set of these historical colors as a ready-to-paste hex list – useful for quick categorical palettes, or just for the pleasure of finding out your data happens to be “Arterial Blood Red” or “Skimmed-milk White.”

How many colors should you randomize?

There’s no universal “right” number, but two lines of vision-science research give a useful working range:

  • Below ~4, people reliably hold and recall a set of colors in visual working memory – the classic estimate from change-detection tasks (Luck & Vogel, 1997; Ngiam et al., 2023).
  • Beyond roughly 8-10, categorical color palettes get measurably harder to read accurately, and common design tools (e.g. ColorBrewer’s qualitative sets) cap out around 12 (Healey, 1996; Tseng et al., 2023).

So the randomizer below defaults to 5 colors and caps at 12 – past that point you’re better served by a sequential or continuous scale than a hand-picked categorical one.

Try it

Show the R 
data = FileAttachment("../data/werner-colors.csv").csv({typed: true})
groupNames = Array.from(new Set(data.map(d => d.group))).sort()
groupOptions = ["All classifications", ...groupNames]
Show the R 
viewof groupChoice = Inputs.select(groupOptions, {label: "Classification", value: "All classifications"})
Show the R 
filtered = groupChoice === "All classifications" ? data : data.filter(d => d.group === groupChoice)
maxN = Math.min(12, filtered.length)
Show the R 
viewof n = Inputs.range([1, maxN], {label: "Number of colors", step: 1, value: Math.min(5, maxN)})
Show the R 
viewof shuffleSeed = Inputs.button("Randomize", {value: 0, reduce: v => v + 1})
Show the R 
sample = {
  shuffleSeed;
  return d3.shuffle(filtered.slice()).slice(0, n);
}
hexList = sample.map(d => d.hex).join("\n")
Show the R 
function textColor(hex) {
  const c = hex.replace("#", "");
  const r = parseInt(c.substring(0, 2), 16);
  const g = parseInt(c.substring(2, 4), 16);
  const b = parseInt(c.substring(4, 6), 16);
  const lum = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
  return lum > 0.6 ? "#241C1C" : "#FFFFFF";
}

}
