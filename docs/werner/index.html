Werner

Randomized palettes from a 1814 color classification system

Abraham Gottlob Werner was a German geologist who, in the late 1700s, developed a standardized color-naming system so mineralogists could describe rock and mineral color consistently. In 1814 (2nd ed. 1821), Scottish flower painter Patrick Syme illustrated and expanded Werner’s system into 110 named colors, organized into 10 classifications (White, Grey, Black, Blue, Purple, Green, Yellow, Orange, Red, Brown) – each cross-referenced against an animal, a plant, and a mineral where that color occurs in nature. Charles Darwin carried a copy on the Beagle to describe organisms and landscapes with a shared, precise color vocabulary.

Palette Jack’s Werner mode lets you filter by classification and pull a randomized set of these historical colors as a ready-to-paste hex list – useful for quick categorical palettes, or just for the pleasure of finding out your data happens to be “Arterial Blood Red” or “Skimmed-milk White.”

library(tidyverse)
library(glue)

werner <- read_csv("../data/werner-colors.csv")

swatch_html <- function(hex, name, cap = 8) {
  n <- length(hex)
  hex <- head(hex, cap)
  name <- head(name, cap)
  spans <- glue('<span class="mini-swatch" style="background:{hex}" title="{name}"></span>')
  out <- paste(spans, collapse = "")
  if (n > cap) out <- paste0(out, glue('<span class="palette-module-more">+{n - cap} more</span>'))
  out
}

gallery <- werner |>
  group_by(group) |>
  summarise(
    n_colors = n(),
    examples = paste(head(name, 4), collapse = ", "),
    swatches = swatch_html(hex, name),
    .groups = "drop"
  ) |>
  arrange(group)

cat(
  '<div class="palette-gallery">',
  glue_data(
    gallery,
    '<div class="palette-module">
  <h4>{group} <span class="palette-module-count">{n_colors} colors</span></h4>
  <p class="palette-module-desc">e.g. {examples}</p>
  <div class="palette-module-swatches">{swatches}</div>
</div>'
  ),
  '</div>',
  sep = "\n"
)

How to use it

  1. Pick a classification below (or leave it on “All classifications”).
  2. Drag the slider to choose how many colors you want – it caps at 12, since legibility drops off past that point (see citations below).
  3. Click Randomize, then copy the R vector – or the plain hex list – straight into your plot.

function textColor(hex) {
  const c = hex.replace("#", "");
  const r = parseInt(c.substring(0, 2), 16);
  const g = parseInt(c.substring(2, 4), 16);
  const b = parseInt(c.substring(4, 6), 16);
  const lum = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
  return lum > 0.6 ? "#241C1C" : "#FFFFFF";
}

vectorCopyBtn = {
  const label = () => `Copy R vector (${sample.length})`;
  const btn = html`<button class="swatch-copy-btn">${label()}</button>`;
  btn.onclick = () => {
    navigator.clipboard.writeText(hexVector).then(() => {
      btn.textContent = "Copied!";
      setTimeout(() => { btn.textContent = label(); }, 1200);
    });
  };
  return btn;
}
