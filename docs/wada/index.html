Wada

2-, 3-, and 4-color combinations from Sanzo Wada’s Dictionary of Color Combinations

Sanzo Wada was a Japanese textile and costume designer whose 1933 reference book, A Dictionary of Color Combinations (配色総鑑), catalogued 348 named colors alongside hundreds of pre-tested pairings meant to be visually harmonious together – closer to a curated palette-pairing tool than a raw color list. Each base color in this mode’s data is matched to one, two, or three other colors Wada specifically paired with it, giving combos of 2, 3, or 4 total colors.

Palette Jack’s Wada mode lets you pick a combo size, randomize to one of Wada’s own matched sets, and copy it straight into scale_fill_manual().

library(glue)

wada <- read_csv("../data/sanzo_wada_colors_long.csv")

swatch_html <- function(hex, name, cap = 8) {
  n <- length(hex)
  hex <- head(hex, cap)
  name <- head(name, cap)
  spans <- glue('<span class="mini-swatch" style="background:{hex}" title="{name}"></span>')
  out <- paste(spans, collapse = "")
  if (n > cap) out <- paste0(out, glue('<span class="palette-module-more">+{n - cap} more</span>'))
  out
}

# a base color's combo size is itself + however many colors Wada matched to
# it (one row per match) -- see R/prep-wada.R for the same logic documented
# and validated outside the render path
wada_bases <- wada |>
  group_by(color_name) |>
  summarise(color_hex = first(color_hex), n_matches = n(), .groups = "drop") |>
  mutate(combo_size = n_matches + 1)

gallery <- wada_bases |>
  filter(combo_size %in% 2:4) |>
  group_by(combo_size) |>
  summarise(
    n_combos = n(),
    examples = paste(head(color_name, 4), collapse = ", "),
    swatches = swatch_html(color_hex, color_name),
    .groups = "drop"
  ) |>
  arrange(combo_size) |>
  mutate(label = glue("{combo_size}-color combo"))

cat(
  '<div class="palette-gallery">',
  glue_data(
    gallery,
    '<div class="palette-module">
  <h4>{label} <span class="palette-module-count">{n_combos} combos</span></h4>
  <p class="palette-module-desc">e.g. {examples}</p>
  <div class="palette-module-swatches">{swatches}</div>
</div>'
  ),
  '</div>',
  sep = "\n"
)

How to use it

  1. Pick a combo size – 2, 3, or 4 colors.
  2. Click Randomize to pull one of Wada’s own matched combinations at that size.
  3. Copy the R vector – or the plain hex list – straight into your plot.

// sorted back into Wada's original order (combo_index is internal only --

grouped = Array.from(

    color_name,
    color_hex: matches[0].color_hex,
    combo_size: matches.length + 1,

function textColor(hex) {
  const c = hex.replace("#", "");
  const r = parseInt(c.substring(0, 2), 16);
  const g = parseInt(c.substring(2, 4), 16);
  const b = parseInt(c.substring(4, 6), 16);
  const lum = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
  return lum > 0.6 ? "#241C1C" : "#FFFFFF";
}
