Pantone’s Color of the Year, 2000-present

Pantone’s PMS system itself is proprietary and trademarked, so this mode doesn’t touch it. What it does cover is the Color of the Year – one color (twice, two) that the Pantone Color Institute names each December, publicly, in its own press releases. Pick a year below and copy the hex.

pData = FileAttachment("../data/pantone-coty.csv").csv({typed: true})

pFiltered = pData.filter(d => d.year === pYear)
pHexList = pFiltered.map(d => d.hex).join("\n")
Show the R 
function pTextColor(hex) {
  const c = hex.replace("#", "");
  const r = parseInt(c.substring(0, 2), 16);
  const g = parseInt(c.substring(2, 4), 16);
  const b = parseInt(c.substring(4, 6), 16);
  const lum = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
  return lum > 0.6 ? "#241C1C" : "#FFFFFF";
}

Show the R 
pCopyBtn = {
  const label = () => `Copy ${pFiltered.length} hex code${pFiltered.length === 1 ? "" : "s"}`;
  const btn = html`<button class="swatch-copy-btn">${label()}</button>`;
  btn.onclick = () => {
    navigator.clipboard.writeText(pHexList).then(() => {
      btn.textContent = "Copied!";
      setTimeout(() => { btn.textContent = label(); }, 1200);
    });
  };
  return btn;
}

Hex codes are sRGB approximations of Pantone’s proprietary ink formulations (TCX/TPX), not an official Pantone conversion – expect them to vary slightly by source and render differently than a physical Pantone chip.
